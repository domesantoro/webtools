# Sito vetrina Webtool

Prototipo statico multipagina costruito dalla specifica fornita.

## File
- index.html
- che-cos-e.html
- esempi.html
- come-funziona.html
- quanto-costa.html
- contatti.html
- styles.css
- script.js

## Elementi lasciati volutamente aperti
- nome definitivo e logo
- indirizzo email ufficiale
- dati identificativi/fiscali
- testi legali effettivi
- gateway futuri "Inizia" e "Lavora con noi"

Per provarlo basta aprire `index.html` oppure servire la cartella con un server statico locale.
