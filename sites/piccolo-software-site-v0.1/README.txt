Prima della pubblicazione
-------------------------
1. Sostituire "Piccolo Software" se scegli un altro nome.
2. Sostituire tuoindirizzo@example.com.
3. Personalizzare chi-sono.html con nome, profilo e competenze.
4. Verificare/aggiornare il prezzo.
5. Completare privacy.html con dati reali.
6. Aggiungere eventuali dati fiscali necessari nel footer.
7. Se aggiungi analytics, cookie o form server-side, aggiornare privacy/cookie policy.

Tecnologia
----------
Solo HTML + CSS.
Nessun framework.
Nessuna dipendenza.
Nessun JavaScript.
Apri index.html direttamente oppure servi la cartella con un qualunque web server statico.
