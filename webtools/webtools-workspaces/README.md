# webtools_workspaces

Stores a project's files, in two families: the **specifications** it receives, in
`<storage.root>/<project_id>/specs/spec-vNNN.md`, and the **documents the system writes** for that
project, in `<storage.root>/<project_id>/documents/<kind>/<kind>-vNNN.md`. It stores and does not
decide: that the project exists, and whose it is, is checked by the caller.

Full documentation: `docs/subsystems/workspaces/README.md` (at the root of the workspace).

```sh
npm install                                  # the first time, and after a version change
./webtools_workspaces.sh --start             # port 9400, in the background
./webtools_workspaces.sh --stop
npm test
```

- `POST /projects/{project_id}/specs`, with the `.md` in the body, `X-Spec-Origin: system|third_party` and `X-Uploaded-By: <uid>` → `201 {project_id, version}`.
- `GET /projects/{project_id}/specs/latest` → the `.md`, with `X-Spec-Version`.
- `POST /projects/{project_id}/documents/{kind}`, with the `.md` in the body and no headers → `201 {project_id, kind, version}`. The kinds are `analysis` and `proposal`; `prespec` is not one of them, because the pre-specification is a specification and has its own route.
- `GET /projects/{project_id}/documents/{kind}/latest` → the `.md`, with `X-Document-Version`.

`src/commons/spec_front_matter.js` is a copy generated by
`webtools/configurator/specs_deployer/deploy.sh`: edit the original in `webtools/commons/specs/`.
`src/commons/configuration_client.js` is a copy generated by
`webtools/configurator/configuration_deployer/deploy.sh`: the original is in
`webtools/commons/configuration/`.

The configuration (`listen`, `access.allowed_ips`, `storage.root`, `storage.spec_max_bytes`,
`storage.document_max_bytes`) is read at startup from anagraphics
(`GET /configuration/workspaces`); the source is
`webtools/configurator/configuration/workspaces.json`. No defaults: if anything is missing the
server does not start. Only the variables of `webtools/configurator/bootstrap.env` come from the
environment, and `--start` loads them by itself.
