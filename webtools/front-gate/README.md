# front-gate — the showcase site

A small Node server (`webtools_front_gate`) renders the site's pages from the templates in
`templates/` and serves the static files of `public/`. The values the pages receive come from the
front-gate's configuration in anagraphics (`GET /configuration/front-gate`).

## Configuration

Read **at startup** from anagraphics (`GET /configuration/front-gate`); the source is
`webtools/configurator/configuration/front-gate.json`, loaded into Mongo by
`webtools/configurator/load_configuration.sh` (`start.sh` already does that). No defaults: if
anagraphics does not answer, or a field is missing or invalid, the server prints
`webtools_front_gate is not starting: …` with the field's path and exits with 1. A change shows up
after `webtools/configurator/start.sh --restart`.

| Field | Use |
|---|---|
| `listen.host`, `listen.port` | Where the server listens (today `127.0.0.1:9000`) |
| `subsystems_infos.preanalyst.url` | The "Inizia" button opens this address, in the same tab: the pre-analysis form. `http`/`https` only: the value ends up in an `href` |
| `screen_infos.pricing.standard_price_cents` | The standard tier's price, in euro cents, an integer ≥ 0: `40000` becomes "400 €" in Italian and "€400" in English (the decimals appear only if there are cents) |
| `i18n.locales`, `i18n.fallback_locale` | The languages offered (`["en", "it"]`) and the fallback one (`en`) |
| `i18n.cookie_name`, `i18n.cookie_max_age_seconds` | The language cookie, **the same in every subsystem** (`webtools_locale`), and how long it lasts |
| `i18n.body_max_bytes` | The largest body accepted by `POST /locale` |

Only the variables of `webtools/configurator/bootstrap.env` come from the environment, and
`--start` loads them by itself.

## Structure

```
front-gate/
├── package.json
├── webtools_front_gate.sh   start and stop (--start | --stop), with a PID file
├── src/
│   ├── index.js             server startup: reads the configuration, or exits with 1
│   ├── server.js            routes: pages and static files
│   ├── page.js              address → template, and the data passed to the templates
│   ├── settings.js          the `front-gate` configuration from anagraphics → settings
│   ├── commons/configuration_client.js   a copy generated by the `configuration` deployer
│   └── commons/i18n/        a copy generated by the `i18n` deployer: the languages module and the catalogues
├── templates/               the pages (.njk, nunjucks with autoescape)
│   ├── index.njk, che-cos-e.njk, esempi.njk, come-funziona.njk, quanto-costa.njk, contatti.njk
│   ├── lavora-con-noi.njk   ambassador, driver, autonomous work
│   ├── layout.njk           the shared shell: head, header, footer
│   └── partials/
│       ├── header.njk       menu, language switcher and Contatti, with the current item highlighted
│       ├── footer.njk
│       └── start.njk        the "Inizia" button
└── public/                  static files
    ├── css/styles.css       local style
    ├── css/commons.css      a copy generated by the style deployer, like css/fonts/
    ├── js/main.js           the mobile menu
    └── assets/mark.svg
```

`css/commons.css` and `css/fonts/` are not edited here: the original lives in
`webtools/commons/style/` and is distributed with `webtools/configurator/deploy.sh style`. The
same for `src/commons/configuration_client.js`: the original is in
`webtools/commons/configuration/`, the `configuration` deployer.

## Starting

```sh
./webtools_front_gate.sh --start   # in the background, PID in webtools_front_gate.pid, log in webtools_front_gate.log
./webtools_front_gate.sh --stop
set -a; source ../configurator/bootstrap.env; set +a; npm start   # in the foreground, for debugging
```

Dependencies are installed with `npm install`.

## Routes

| Request | Response |
|---|---|
| `GET /`, `GET /<page>.html` | the page, rendered from `templates/<page>.njk` |
| `GET /<file>` | `public/<file>` |
| `POST /locale` | the language switcher (`locale`, `return_to`): it writes the shared cookie and returns to the page (`303`). `400 {"error":"INVALID_LOCALE"}`, `413 {"error":"BODY_TOO_LARGE"}` |
| a non-existent file, or one outside `public/` | `404 {"error":"ROUTE_NOT_FOUND"}` |
| a method other than `GET`/`HEAD` | `405 {"error":"METHOD_NOT_ALLOWED"}` |
| an unexpected error | `500 {"error":"INTERNAL_ERROR"}` |

Every page extends `layout.njk`, sets `page`, `title` and `description` and fills the `main`
block. The header and the footer exist in one place only: a menu item is added in
`partials/header.njk`.

## Languages

There is no text in the templates: every sentence is a key,
`{{ t("front_gate.<page>.<piece>") }}`, and the texts live in the shared catalogues
`webtools/commons/i18n/locales/<language>.json`, under `front_gate`. Sentences with a marked-up
piece inside them use `t_html`. The pages are in the language of the `webtools_locale` cookie
(shared by every subsystem), or in that of `Accept-Language`, or in English. The pages' addresses
are the same in every language.

To check that every key used exists: `node webtools/commons/i18n/webtools_i18n_check.mjs`.

- "Lavora con noi" is the last item of the menu, before "Inizia". The pre-analysis' autonomous
  work block also links here.

- No definitive brand name has been invented: the service is called "webtools"; "webtool" remains
